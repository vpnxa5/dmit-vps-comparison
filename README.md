## 三条线路，搞清楚再下单

DMIT 每个机房都有三个产品系列，线路是最核心的区别，配置倒是其次。

**Premium（Pro 系列）**：旗舰线路，洛杉矶和香港版本都带 CN2 GIA 回程，电信用户感受最明显。延迟稳，晚高峰不掉速，是三网里对大陆最友好的选择。价格最贵。

**Eyeball（EB 系列）**：折中选项。洛杉矶版本走电信联通 AS9929 + 移动 CMIN2 回程；香港版本是三网 CMI 优化。比 T1 强，比 Pro 便宜，适合预算有限但还是想要比普通国际线路好一些的场景。

**Tier 1（T1 系列）**：纯国际线路，没有专门的大陆优化，但接入了多个国际 Tier 1 运营商。流量配额是三个系列里最大的，超量后限速继续用而不是直接停机——这个设计很适合流量消耗大的场景。价格最便宜。

## FAQ

**Q：DMIT 的 VPS 可以换 IP 吗？**

A：洛杉矶 LAX Pro 和 LAX EB 系列支持自助更换 IP，包括部分促销套餐都覆盖。可以在用户后台直接操作，适合需要灵活切换 IP 的场景。

**Q：AN4 和 AN5 平台有什么区别？选哪个？**

A：AN4 是 AMD EPYC 9004 处理器，AN5 是更新一代的 EPYC 9005，单核性能和多线程跑分都有提升。AN5 价格贵一些。个人用途、跑网站、代理节点的话 AN4 完全够用；跑数据库密集型应用或者高并发服务，AN5 更合适。

**Q：国内用哪家运营商访问 DMIT 效果好？**

A：Premium 系列（CN2 GIA）三网都有优化，但电信用户体验最明显——去程和回程都走 CN2 GIA。联通用户用 Eyeball 系列的 AS9929 线路也有不错的效果。移动用户选 CMI 线路的套餐（香港 Eyeball 或洛杉矶 EB 的移动方向）。

**Q：流量超了会怎样？**

A：T1 系列超量后限速继续用，洛杉矶限速 1Gbps，香港/东京限速 50Mbps，不会直接断网停服。Premium 和 EB 系列超量后带宽受限，具体看套餐页面说明。

**Q：支持支付宝付款吗？**

A：支持。DMIT 接受支付宝、微信支付、PayPal、信用卡，国内用户付款没有障碍。
